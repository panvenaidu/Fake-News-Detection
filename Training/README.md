# Training materials

Training notebooks, implementation scripts, and cloud launch helpers are grouped by model input:

- Text Only: BERT-base notebooks and training scripts.
- Image Only: ResNet-50 notebook and training script.
- Text + Image: multimodal notebooks and the registered BERT + ResNet training implementation.
- Templates: reusable notebook templates.
- Archive: superseded notebook and pilot material retained for history.

Configuration files are in Configuration/. Data-preparation notebooks are in Pre-processing/Notebooks/. Validation checks and frozen test evaluation code are in Validation/ and Testing/.

Many files are historical launch artifacts. Read AGENTS.md and check embedded paths and current receipts before rerunning a cloud or training script.
