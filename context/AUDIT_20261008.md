Pin source-file hashes and pretrained revisions. Configuration: `configs/text_official_6way_v2.json`; implementation: `scripts/train_official_text.py`; runnable local notebook: `notebooks/UROP_OFFICIAL_6WAY_TEXT_20261008.ipynb`.

Batch 32, max length 128, fp16, SDPA attention on Colab T4, 6-epoch cap, minimum 3 epochs, patience 2 with macro-F1 min-delta 0.001. AdamW with separate bias/normalization groups; linear 10% warmup; learning rates 2e-5 BERT and 3e-5 ModernBERT. Best checkpoint uses validation macro-F1, then lower validation loss, then earlier epoch. Test runs once per predeclared model after checkpoint selection. Do not choose hyperparameters using test scores.

Outputs: accuracy, macro-F1, weighted-F1, balanced accuracy, loss, class reports, confusion matrices, per-item predictions, epoch histories, actual environment/frozen packages, GPU memory/time, model configuration, source copy, best weights and recovery checkpoint every 3,000 batches and at epoch boundaries.
